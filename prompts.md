# Промпты, которые использовадись для создания трекера

## V1. Одно сообщение
Использловалось одно сообщение следующего содердания:

Создай мини-трекер учебных задач в одном HTML-файле. Нужны название задачи, оценка в часах, отметка «готово», добавление и удаление, фильтр «все / активные / готовые», суммарные часы и процент выполнения. Добавь пример: «Чтение» 2 ч готово, «Практика» 4 ч активно, «Повторение» 2 ч активно. Сделай удобный интерфейс. Всё должно работать в обычном браузере без установки библиотек и без внешних ресурсов. Верни полный HTML.
