# Дизайн

## Данные

Каждая задача представлена объектом со следующими полями:

- `id` — уникальный идентификатор задачи;
- `title` — название после проверки через `trim`;
- `hours` — число часов, кратное 0,5, в диапазоне от 0,5 до 24;
- `done` — логическое значение статуса выполнения.

Начальное состояние:

| Название | Часы | Выполнено |
|---|---:|---|
| Чтение | 2 | Да |
| Практика | 4 | Нет |
| Повторение | 2 | Нет |

## Изменение данных

- Добавление создаёт новую задачу только после успешной проверки обоих полей.
- Удаление удаляет задачу по `id`.
- Переключение статуса меняет `done` выбранной задачи.
- Фильтрация формирует только отображаемый список и не удаляет и не изменяет исходные задачи.

## Расчёты

Для всех задач:

- `totalHours = сумма hours`;
- `doneHours = сумма hours для задач с done=true`;
- если `totalHours = 0`, `progress = 0`;
- иначе `progress = round(100 × doneHours / totalHours)`.

Для стартового списка `totalHours = 8`, `doneHours = 2`, `progress = 25%`. После отметки «Практики» как выполненной значения составят 8 ч, 6 ч и 75%.

## Хранение

Основное состояние может оставаться в памяти страницы. Если реализовано необязательное сохранение, задачи записываются и восстанавливаются из `localStorage`. При ошибке чтения или записи работа продолжается в памяти с понятным сообщением. При `file://` работа `localStorage` зависит от браузера.
