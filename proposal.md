# Proposal: мини-трекер учебных задач

## Цель

Подготовить автономный мини-трекер учебных задач на неделю. Пользователь может добавлять и удалять задачи, отмечать их выполненными и смотреть общий прогресс.

## Границы

- Для варианта A итоговая реализация — один файл `tracker-v2.html` со встроенными CSS и JavaScript.
- Трекер работает без CDN, внешних библиотек и API-ключей.
- Задача содержит `id`, `title`, `hours` и `done`.
- В стартовом примере три задачи: «Чтение» — 2 ч, выполнено; «Практика» — 4 ч, не выполнено; «Повторение» — 2 ч, не выполнено.
- Фильтр меняет только видимые задачи; общие часы и прогресс считаются по всему списку.
- Сохранение в `localStorage` — необязательное улучшение.
- В спецификацию не входят другие функции, форматы хранения или интеграции.
